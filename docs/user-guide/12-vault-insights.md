# Vault insights

Vault insights shows how callouts are used across every Markdown note.

## View callout statistics

Open **Settings → Callout Studio**, scroll to **Vault insights & maintenance**, and open **Callout statistics**.

The report counts every Block, Heading, and Inline callout and shows:

- The total number of callouts.
- Which types are used most often.
- Which saved types have not been used.
- How many notes contain each type.
- How each type is written: Block, Heading, or Inline.

Callouts that appear in notes but have not been saved in Callout Studio are included too and identified as not defined. You can then return to **My callout types** and use **Scan for callouts** if you want to save them.

For a quick count of one specific type, open that callout's three-dot menu in settings.

## Scanning behavior

On the first launch, a small vault is scanned quietly in the background. A large vault with more than 500 notes asks before starting so the scan does not interrupt your work.

Use **Re-scan vault** whenever you want to refresh the report after changing your notes.
