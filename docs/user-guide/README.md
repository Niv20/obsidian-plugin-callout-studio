# Callout Studio user guide

This guide covers everything Callout Studio can do in plain language. Each
chapter stands on its own, so you can jump to the task you need or read the
guide from the beginning.

| Chapter | What it covers |
| --- | --- |
| [01 - Three ways to use a callout](01-three-ways-to-use-a-callout.md) | Use one callout type as a block, heading, or inline callout. |
| [02 - Creating your first callout](02-creating-your-first-callout.md) | Create callouts with `[!` autocomplete or the callout editor. |
| [03 - Colors and color palettes](03-colors-and-color-palettes.md) | Set light and dark colors, use presets, and save reusable palettes. |
| [04 - Global callout style](04-global-callout-style.md) | Set shared borders, corners, spacing, and scale. |
| [05 - Heading callouts, the Outline, and links](05-heading-callouts-the-outline-and-links.md) | See how heading callouts work with the Outline and links. |
