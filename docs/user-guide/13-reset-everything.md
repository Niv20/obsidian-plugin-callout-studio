# Reset everything

Use **Reset everything** only when you want to return Callout Studio to a clean state.

Open **Settings → Callout Studio**, scroll to **Maintenance**, find the **Reset** row, and click **Reset everything**.

The reset removes or restores:

- Every custom callout you created.
- Customizations to Obsidian's built-in callouts.
- Global styles, including borders, font scale, shape, spacing, and alignment.
- Saved color palettes.
- Right-click menu customization.
- Downloaded Material Symbols artwork and other resettable cached data.

Callouts supplied by the active theme are not deleted from the theme. They remain available while that theme is active.

Before the reset runs, Callout Studio shows a confirmation with any relevant warning about custom types used in your notes. Read it carefully. **Reset everything cannot be undone.** Export a [complete backup](10-import-export-and-sharing.md) first if you may want the setup later.

To undo only one icon or color, use the return arrow in the callout editor. To restore one customized built-in callout, use **Reset to default** from that callout's three-dot menu instead.
