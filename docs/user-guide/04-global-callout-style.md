# Global callout style

Global styles control the shape and spacing of each callout form across your vault. Set them once instead of repeating the same changes for every callout type.

![Global callout style](https://github.com/user-attachments/assets/7558c077-1396-43de-9715-6538b4ca8297)

## What it applies to

These settings apply only to callouts **drawn by Callout Studio**. Callouts supplied or restyled by your theme keep the theme's border, corner radius, text size, and other geometry. If a setting seems to skip a callout, check which list contains it. See [Using Callout Studio with your theme](12-using-callout-studio-with-your-theme.md).

## Where to find it

Open **Settings → Global settings**. Block Callouts, Heading Callouts, and Inline Callouts each have their own style popup, so you can shape each form independently without affecting the others.

## Block callout style

From the **Block callout** style popup you can control:

- Which **border** sides are drawn, and how thick they are.
- **Corner rounding** for the callout box.
- An independent **Title scale** and **Content scale**, so you can size the title text and the body text separately.
- An option to **align content with title**, which lines up the body text with the title instead of the icon.

## Heading callout style

From the **Heading callout** style popup you can control:

- Which **border** sides are drawn, and how thick they are.
- **Corner rounding** for the heading.
- **Vertical padding** around the heading text.
- A **horizontal icon inset**, which adjusts the icon's spacing from the edge.

## Inline callout style

From the **Inline callout** style popup you can control:

- Which **border** sides are drawn, and how thick they are.
- **Corner rounding** for the inline callout.
- A dedicated **font scale** just for inline callout text, separate from the rest of your note.

This is different from the per-callout colors covered in the previous chapter: colors are set individually for each callout type, while these global style settings shape the structure of every Block, Heading, or Inline callout at once.
